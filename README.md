### 🚀 Featured project

**[SketchScreens](https://sketchscreens.com)** — auto-generate hand-drawn sketch wireframes of any app's screens + user-journey flow, straight from its source code. Local-first, agent-driven, open source.

[![npm](https://img.shields.io/npm/v/sketchscreens?color=2f6f8f&label=npm)](https://www.npmjs.com/package/sketchscreens)
[![repo](https://img.shields.io/badge/GitHub-sketchscreens-2f6f8f?logo=github)](https://github.com/RORHITD/sketchscreens)

```bash
npx sketchscreens --help
```

> Point it at a repo → it finds the screens, the fields/buttons on each, and how you navigate between them → draws it all as a hand-sketched wireframe map you can review without ever opening the running app.
